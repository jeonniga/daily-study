독해 지문

Some public libraries lend tools as well as books. This service allows residents to borrow equipment that they need only occasionally. By sharing resources, communities can reduce unnecessary purchases.

Volunteers teach beginners how to use tools safely. Each workshop is designed to help participants gain confidence. Since the service began, many residents have learned to make simple repairs.

Although not every repair will succeed, the program encourages people to try new skills. It also creates opportunities for neighbors to exchange knowledge. Such programs show that libraries can support learning in many different ways.
